# Hidden Tourism Assets - Web GIS

This repository contains the source code for the "Interactive Participatory Web GIS for Mapping Hidden Tourism Assets and Student-Led Destination Discovery in the Western Province" project. 

Developed for PL 3508: Advance GIS and Remote Sensing for Planning.

## Features
- Interactive Web Map using Leaflet.js
- Crowdsourced data entry for public interaction
- Category-based filtering

## How to run locally
1. Clone this repository.
2. Open `index.html` in your web browser.

## Deployment
This project is configured to be hosted on GitHub Pages.
